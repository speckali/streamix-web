Politique de confidentialité

Dernière mise à jour : 25 novembre 2026

STREAMIX collecte le minimum : un identifiant de l'appareil, l'état de la licence et, si vous les envoyez depuis votre téléphone, vos liens de playlist. Aucune publicité, aucun pistage, aucune revente de données.

Données qui restent sur la TV

Les playlists saisies directement sur la TV, les favoris, l'historique « Déjà vus », les positions de reprise et les réglages sont enregistrés uniquement dans la mémoire de la TV. Ils ne sont pas envoyés à STREAMIX. Désinstaller l'application ou utiliser « Effacer toutes les données » dans Réglages les supprime.

Données bancaires

Le numéro de carte est saisi chez Stripe et n'est jamais vu ni conservé par STREAMIX.

Contenus regardés

STREAMIX ne transmet à personne la liste de ce que vous regardez. Les vidéos sont lues directement depuis le serveur de votre fournisseur. Dans la version navigateur, si ce serveur refuse la connexion directe, la demande peut passer par un relais technique de STREAMIX, sans être enregistrée.

Sous-traitants

Supabase (serveur de l'application, données dans l'Union européenne), Stripe (paiement), GitHub (hébergement du site). Certains de ces prestataires sont américains ; les transferts éventuels hors de l'Union européenne sont encadrés par les clauses contractuelles types de la Commission européenne ou le cadre de protection des données UE–États-Unis.

Vos droits

Vous pouvez demander l'accès, la rectification, la suppression ou la portabilité de vos données, ou vous opposer à un traitement, en écrivant à streamix62@gmail.com avec l'adresse MAC de votre TV. Réponse sous un mois. Vous pouvez aussi déposer une réclamation auprès de la CNIL (www.cnil.fr).

Mineurs

L'achat est réservé aux personnes majeures ou autorisées par leurs parents. Un code parental permet de bloquer les catégories pour adultes.
